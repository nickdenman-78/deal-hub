# Shared Context Ubiquitous Language

This glossary is the canonical language source for `SharedContext` (`modelling/ddd/shared/shared.cml`).

Only include terms that are genuinely cross-context and stable enough for shared-kernel ownership. A term
used by a single context belongs in that context's glossary.

## Entry format

```markdown
### Term
- **Definition:** What it means, precisely enough to settle an argument.
- **Owning context:** SharedContext
- **Allowed synonyms:** Words that may be used for it (or None)
- **CML element:** `ValueObject Term`
```
